## 

این پروژه با هدف آموزش تخصصی هک، امنیت و مقابله با تهدیدات مدل‌های زبانی بزرگ (LLMs) و هوش مصنوعی مولد طراحی شده است. این پلتفرم بر اساس استانداردهای جهانی مانند **OWASP Top 10 for LLM**، **MITRE ATLAS** و تجربیات عملی **Red Teaming** توسعه یافته است.

### 🌟 قابلیت‌ها و بخش‌های اصلی (Features)
  
1. **فید خبری زنده (Live Threat Intel):**
   - اتصال به API گیت‌هاب جهت واکشی لحظه‌ای جدیدترین ابزارها و آسیب‌پذیری‌های حوزه AI Security. دارای افکت Ticker و Hover-to-Pause.

2. **گراف فیزیکی دانش آسیب‌پذیری‌ها (Interactive Cyber Graph):**
   - پیاده‌سازی شده با **D3.js**. یک شبکه عصبی فیزیکی (Force-Directed) که ارتباط بین حملات، آسیب‌پذیری‌ها و مکانیزم‌های دفاعی را با قابلیت تعامل (Drag & Drop) و افکت‌های نئونی به تصویر می‌کشد.

3. **پلتفرم‌های تمرین آنلاین (Online Practice Platforms):**
   - معرفی و اتصال به پلتفرم‌های تخصصی تمرین هک کلاه‌سفید مانند **Lakera Gandalf** (بازی فرار از گاردریل‌ها) و **Promptfoo**.

4. **پوشش جامع سرفصل‌های امنیتی:**
   - **آسیب‌پذیری‌های OWASP:** از Prompt Injection تا Data Poisoning.
   - **تکنیک‌های Red Teaming:** بای‌پس‌های پیشرفته، Payload Splitting و Roleplay.
   - **ماتریس MITRE ATLAS:** فازهای مختلف چرخه حمله به هوش مصنوعی.
   - **امنیت چندرسانه‌ای (Multi-Modal):** حملات نویز تصویری (Adversarial Noise) و دیپ‌فیک صوتی.
   - **چک‌لیست امنیتی (Audit):** جدول ارزیابی دفاعی سیستم‌ها.
   - **معرفی ابزارها:** Garak، Llama Guard و NeMo Guardrails.

5. **تابلوی افتخارات جهانی هکرها (Hacker Leaderboard):**
   - شبیه‌ساز ثبت تکنیک‌های موفق (Payloads) همراه با قابلیت **جستجوی پیشرفته (Search)** و قالب‌بندی جذاب.

## 

This project aims to provide specialized training in hacking, security, and countering threats of Large Language Models (LLMs) and Generative Artificial Intelligence. The platform is developed based on global standards such as **OWASP Top 10 for LLM**, **MITRE ATLAS**, and **Red Teaming** practical experiences.

### 🌟 Key Features

1. **Live Threat Intel Feed:**
   - Integrates with the GitHub API to fetch real-time updates on AI Security tools and vulnerabilities. Features a custom CSS Ticker with Hover-to-Pause functionality.

2. **Interactive Cyber Vulnerability Graph:**
   - Built with **D3.js**. A force-directed physics graph visualizing the relationships between attacks, vulnerabilities, and defenses. Fully interactive (draggable nodes) with cyberpunk neon glow effects.

3. **Online Practice Platforms:**
   - Curated directory linking to premier white-hat AI hacking platforms like **Lakera Gandalf** (jailbreak simulations) and **Promptfoo**.

4. **Comprehensive Security Curriculum:**
   - **OWASP Vulnerabilities:** From Prompt Injections to Training Data Poisoning.
   - **Red Teaming Techniques:** Advanced bypasses, Payload Splitting, and Persona Adoption.
   - **MITRE ATLAS Matrix:** Adversary tactics lifecycle against AI systems.
   - **Multi-Modal Security:** Adversarial Image Noise and Audio Deepfakes.
   - **Security Audit Checklist:** Defensive evaluation tables.
   - **Essential Tools:** Introductions to Garak, Llama Guard, and NeMo Guardrails.

5. **Global Hacker Leaderboard:**
   - A simulated submission panel for successful payloads, featuring advanced **live search** capabilities and responsive tabular design.
